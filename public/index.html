secrets toolkit for devops

Passwords and random tokens, htpasswd for Envoy and ArgoCD, a Kubernetes Secret builder and decoder, a JWT inspector and checksums. Everything is computed in the browser. There is no fetch anywhere in the page, and the Content-Security-Policy header forbids network calls outright with connect-src 'none' — so the guarantee is enforced by your browser rather than promised in a paragraph.

client-side only csprng rejection sampling no telemetry mit licensed

A random password over an alphabet you choose. Randomness comes from window.crypto.getRandomValues(), and the index into that alphabet is drawn by rejection sampling rather than a modulo — so every character is equally likely and there is no modulo bias.

        The single quotes in the generated commands are not cosmetic: bcrypt and apr1 hashes contain $, and inside double quotes bash would try to expand $2a as a variable. The other landmine is line endings — Envoy rejects a .htpasswd with CRLF endings while the SecurityPolicy cheerfully reports Accepted: True, leaving the real error visible only in the Envoy logs. Everything here is separated by a single LF.

Privacy & cryptography

    


    

      

        
Privacy

        
    
          
  • Computed in the browser — there is no fetch, no XMLHttpRequest and no sendBeacon anywhere in the page. Open DevTools, watch the Network tab, and check for yourself.
    • 
          
  • Enforced by the browser — the CSP header carries connect-src 'none'. Even if a network call did appear in the page, the browser would block it.this is the one claim here you can verify without reading any code
    • 
          
  • There is exactly one external request — the fonts from Google Fonts. It happens while the page loads, before you have typed anything, and it carries none of your input. Self-hosting them is on the list.more honest than writing "no network" and quietly omitting this
    • 
          
  • No analytics, no cookies — the only thing stored is your theme choice in localStorage.
    • 
          
  • Logs — nginx keeps an ordinary access log: path, status, user agent. What you type into the forms is not in it and cannot be: it never leaves the tab.
    • 
          
  • Source is public — github.com/AaronShemtov/pwd-frontend
    • 
        

      

      

        
Cryptography

        
    
          
  • CSPRNG — randomness comes from window.crypto.getRandomValues(), backed by the operating system entropy pool.never Math.random — that is a plain PRNG, predictable after a handful of samples
    • 
          
  • Uniform distribution — the index into the alphabet is drawn by rejecting any value above the last whole multiple.random % N is biased whenever N does not divide 2³² evenly
    • 
          
  • bcrypt — implemented here, with no external dependency. The Blowfish constants are not typed from memory: they are derived from the hexadecimal expansion of π, exactly as in the original paper.cross-checked against a reference implementation, including UTF-8 and the 72-byte boundary
    • 
          
  • apr1 — a thousand salted MD5 rounds, the same dance Apache does. Cross-checked against passlib.
    • 
          
  • SHA-1 and SHA-2 — from WebCrypto, meaning native browser code.
    • 
          
  • Entropy — computed as log₂(alphabet size) × length, the theoretical maximum for uniform randomness.
