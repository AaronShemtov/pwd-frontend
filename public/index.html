Набор инструментов для секретов, которые каждый день нужны в работе с Kubernetes: пароли и токены, htpasswd для Envoy и ArgoCD, сборка и разбор Secret, разбор JWT, контрольные суммы. Всё считается прямо в браузере: в коде страницы нет ни одного сетевого вызова, а заголовок Content-Security-Policy запрещает их директивой connect-src 'none' — то есть запрет обеспечивает браузер, а не обещание в тексте.

Приватность и криптография

    


    

      

        
Приватность

        
    
          
  • Считается в браузере — в коде страницы нет ни fetch, ни XMLHttpRequest, ни sendBeacon. Открой DevTools на вкладке Network и убедись сам.
    • 
          
  • Запрет на уровне браузера — заголовок CSP содержит connect-src 'none'. Даже если бы в странице появился сетевой вызов, браузер бы его заблокировал.это единственное утверждение здесь, которое проверяется без чтения кода
    • 
          
  • Один внешний запрос всё же есть — шрифты с Google Fonts. Он происходит при загрузке страницы, до того как ты что-либо ввёл, и никаких твоих данных не содержит. Самохостинг шрифтов в планах.честнее сказать так, чем писать «no network» и умолчать
    • 
          
  • Ни аналитики, ни кук — единственное, что сохраняется, это выбранная тема в localStorage.
    • 
          
  • Логи — nginx пишет обычный access-log: путь, код ответа, user-agent. Того, что ты вводишь в формы, там нет и быть не может: это никогда не покидает вкладку.
    • 
          
  • Исходники открыты — github.com/AaronShemtov/pwd-frontend
    • 
        

      

      

        
Криптография

        
    
          
  • CSPRNG — случайность берётся из window.crypto.getRandomValues(), за которым стоит системный источник энтропии.никогда не Math.random — это обычный ГПСЧ, предсказуемый после нескольких выборок
    • 
          
  • Равномерность — индекс в алфавите выбирается отбраковкой значений выше последней полной кратности.random % N смещён всякий раз, когда N не делит 2³² нацело
    • 
          
  • bcrypt — своя реализация, без внешних зависимостей. Константы Blowfish не вписаны по памяти, а выведены из шестнадцатеричного разложения числа π, как в оригинальной статье.сверено с эталонной реализацией, включая UTF-8 и границу в 72 байта
    • 
          
  • apr1 — тысяча проходов MD5 с солью, ровно как в Apache. Сверено с passlib.
    • 
          
  • SHA-1 и SHA-2 — из WebCrypto, то есть нативный код браузера.
    • 
          
  • Энтропия — считается как log₂(размер алфавита) × длина, то есть теоретический максимум для равномерной случайности.
